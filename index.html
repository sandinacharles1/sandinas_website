I’m a 16-year-old computer engineering junior at Florida Atlantic University focused on backend engineering and secure data systems.

I’m based in Lauderdale Lakes, Florida, and expect to graduate in May 2028.

Sandinify: Music Uploading, Listening, and DSP Editor Platform

Started: Sep 2026   Status: In progress   Code
  • Blocks brute-force attempts and request flooding with a Redis-backed token-bucket rate limiter (100-token capacity, 0.5 tokens/s refill) built as a Spring Boot filter that returns HTTP 429. An atomic Lua script keeps concurrent requests from racing.
  • Handles authentication and authorization with signup and login REST endpoints, JWT access tokens (HS256, 15-minute expiry), and refresh tokens, using Spring Data JPA/Hibernate, PostgreSQL, and Argon2id password hashing.
  • Starts with one command: the API, PostgreSQL, and Redis run together in Docker Compose, and the React.js login screen is built.
Java · Spring Boot · Hibernate/JPA · PostgreSQL · Redis · Docker Compose · React.js
